# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming. Assume good intent.
- No harassment, insults, or personal attacks.
- Critique code and ideas, not people.

To report unacceptable behaviour, use GitHub's **Report content** option or contact the maintainer through their GitHub profile. Reports are handled confidentially.
